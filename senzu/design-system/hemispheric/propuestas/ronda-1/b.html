How it works.

No embeddings, no vector database, no API calls. The Cortex runs entirely on your machine, stores facts in a local graph, and retrieves them with two-hop activation — in milliseconds.

01 — Capture

Your agent talks.
The hook listens.

Hemispheric installs as a PostToolUse hook in Claude Code. After every tool call, it extracts facts from the exchange — file paths, decisions, project context — and writes them to the local Cortex graph.

02 — Store

Facts, not vectors.
Dates, not embeddings.

Each fact lands in a lightweight JSON graph with its entity name, date, and temporal context. No server, no cloud, no API key. The entire Cortex is a single file you own.

03 — Retrieve

Two-hop activation.
No semantic search needed.

When your agent needs context, the Cortex activates the matching node and spreads one hop out — surfacing related facts without a vector DB or embedding model. Deterministic. Offline. Instant.
